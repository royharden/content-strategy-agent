# Structural boundary contracts and remaining proposals

The local product separates structural records from future analytics, validation, model transport and human approval engines. `shared/grounded/` currently exports strict Pydantic structural models and generic resolver protocols; `schemas/grounded-v1.json` is generated by `scripts/export_schemas.py`. No provider, evidence checker, transition engine or side effect is implemented.

| Boundary | Proposed responsibility | Still required |
|---|---|---|
| CSV → metrics | Code computes platform-stratified rates, eligible counts and immutable snapshots | Import/arithmetic implementation, independent oracle tests and fixed gold |
| Metrics → recommendations | Screened brief and computed metrics only; no raw post rows | Exact adopted provider interface, bounded generation and payload tests |
| Citation → evidence | Structural citation fields exist; future checker must match id/value/unit/scope and sample policy | Actual resolver/validator, numeric grammar and conformance |
| Draft → approval | Exact content, parent recommendation and evidence version bind approval | Durable state machine, audit migration and race/restart tests |
| Approval → export | One SQLite transaction stores approved Markdown+CSV bytes, receipt and events | Export implementation and crash/idempotency/unauthorized tests |
| Shared modules | S3 owns providers/callledger; S6 screen; S2 evalkit and optional rulings | Actual owner adoption, verified commits/licences and moved-copy tests |

## Identity edition

Dataset identity `dataset-identity.v1` hashes named source rows sorted by their explicitly supplied ID field, using NFC strings, sorted object keys and canonical UTF-8 JSON. Duplicate IDs/keys after normalization fail. Float/datetime/SDK values are rejected; bounded exact Decimals serialize as plain strings with no exponent, rounding or negative zero. IDs retain case. Semantic category slugs use NFKC/casefold and ASCII runs; all colliding NFC keys get six-hex suffixes, and any remaining collision fails explicitly.

`SnapshotIdentity` hashes its exact versioned structural document: dataset fingerprint, sorted source/field tag provenance, immutable canonical `config_json` text and computation version. Config is a JSON object encoded as a canonical string; decimal config literals must be strings, not JSON floats. Creation timestamps belong to `MetricSnapshot` metadata and never enter this identity. Fields are immutable tuples/records/strings. No mutable configuration dictionary is retained. Changed source/config/tags/computation changes identity; equivalent row/key/Unicode order does not.

`EvidenceResolver[T]` is a protocol over generation/evidence-ID/scope and has no concrete IO implementation or social-platform enum. A corpus-passage or approval-queue consumer may provide its own evidence type. Metric minimum-n and citation validity remain future policy checks. Approval/export record construction and schema checks cannot prove human identity, approved state, actual artifact hashes or permission. Call public validation on untrusted input; Pydantic's deliberately unvalidated `model_construct`/`model_copy(update=...)` are trusted-code escape hatches, not validation boundaries.

Audit DDL, adapters, ledger and exporter remain absent. Foreign provider contract proposals are not vendored source. `config/metric-policy.proposal.json` is proposed analytic configuration, unused at runtime. Product state must never be authorized by a model result, cached response or UI button alone.
