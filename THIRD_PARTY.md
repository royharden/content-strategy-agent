# Dependency and source provenance

This repository includes verified cross-app sources from S2 (evalkit), S3 (ledger/offline providers) and S6 (screen), plus the licensed Python text parser described below. [Published component provenance](docs/VENDORED.md) records the source commits, retained notices, runtime mappings and original/adapted conformance assets. Dependency versions are pinned in the PyPI/npm lockfiles; those pins alone do not establish fresh-install or application acceptance.

The root status command uses the standard library; the structural `grounded` models use pinned Pydantic. Hatchling, pytest and ruff are build/development dependencies. React, React DOM, TypeScript, Vite and Node/React typings are locked frontend tooling for the implemented local browser. The three declaration packages and complete MIT notices have [exact archive/installed-file provenance](conformance/vendor/frontend-types/manifest.json). Both lockfiles are checked locally. The GitHub CI definition includes the commit-pinned upstream setup-uv action; its remote execution remains unobserved.

Exact source and file hashes are retained in the [historical source map](conformance/vendor/manifest.json), [active S3 successor map](conformance/vendor/s3-purpose/manifest.json), [S6 native successor map](conformance/vendor/s6-native/manifest.json) and [S2 evalkit map](conformance/vendor/s2/manifest.json). Historical versions remain identified separately from current runtime sources. Proposed interfaces and synthetic contract checks do not establish live provider behavior or model quality.

## twitter-text-parser and official conformance

The vendored `content_strategy.vendor.twitter_text` is the MIT-licensed 3.0.0 PyPI wheel, edition `3.0.0+stdlib.resources.1`: three import-prefix relocations and two resource-loader compatibility lines. Algorithms, configuration and emoji data are unchanged. Full MIT is included in `src/content_strategy/vendor/LICENSE.twitter-text-parser`; exact original/derived member hashes and the five-line patch are in `conformance/vendor/twitter-text-parser/`. The original installed distribution remains separate.

The separate official Twitter conformance vectors are pinned to upstream commit `65e7e00da383fb77f5ab7fe3c0dc26b724e14035` and retain their Apache-2.0 LICENSE/README in `conformance/vendor/twitter-text-official/`. The Python port MIT licence is not the official Twitter Apache licence. The [parser compatibility provenance and mapped conformance profile](conformance/vendor/twitter-text-parser/README.md) document the selected implementation, required controls and limits of standard X support.
